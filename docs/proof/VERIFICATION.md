# Verification & proof pack

This folder contains reproducible evidence generated by running the application. No client data, API keys or `.env` values are included - the ten sample invoice PDFs used as inputs are stored in `outputs/` and were supplied for this demonstration.

Regenerate with:

```bat
backend\.venv\Scripts\python.exe scripts\verify.py
backend\.venv\Scripts\python.exe scripts\make_demo.py
backend\.venv\Scripts\python.exe scripts\capture_proof.py
```

Exact UTC timestamps and environment details: [`logs/verification.json`](logs/verification.json) and [`logs/screenshots.json`](logs/screenshots.json).

## 2. End-to-end demo run

[`outputs/demo_summary.json`](outputs/demo_summary.json) is written by `scripts/make_demo.py` through the real REST API:

| Step | Result |
|---|---|
| Upload | 10/10 PDFs accepted (FR, UK, DE, CH, ES, US) |
| Processing | 10 queued; 3 processed, 1 reviewed, 6 needs_review, 0 failed, 0 duplicates |
| OCR | `invoice-es-zelsol-servicios-F2025-10190-scanned.pdf` extracted locally with PaddleOCR PP-OCRv6 Medium (`method: ocr`) |
| Locale money | CHF apostrophe thousands (`32'707.88`), French decimal commas and EUR/GBP/USD totals parsed with `Decimal` |
| Prompt injection | Embedded instructions in several PDFs were treated as document text, never executed; suspicious invoices were flagged for review |
| Correction | Scanned invoice total `null` -> `48603.38`; original value preserved and change audited |
| Review | invoice marked reviewed by operator |
| Deliverables | XLSX, invoices CSV, line-items CSV and PDF report generated from the reviewed job |
